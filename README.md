# Masar website

## Run
npm install
npm run dev

## Deploy
Push this folder to GitHub and import the repository into Vercel. Vite should be detected automatically.

## Before public release
1. Replace support@example.com with the real support email.
2. Replace the temporary M arrow graphic with the final Masar icon/image if desired.
3. Rewrite the Privacy Policy to exactly match the final app's actual data collection, SDKs, permissions, retention, and contact details.
4. Verify /app-ads.txt after deployment.
